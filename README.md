# Coffee-Shop-Sales
🚀 Coffee Shop Sales Analysis (Excel Project) ☕📊
Excited to share my latest Excel-based data analytics project where I analyzed coffee shop sales data to uncover key business insights!
🔍 Project Objective
The goal of this project was to analyze retail sales data and generate actionable insights to improve the performance of a coffee shop.
📊 Key Analysis Performed:
✔️ Sales trends by day of the week & hourly analysis to identify peak times
✔️ Monthly revenue analysis to track business growth
✔️ Sales comparison across different store locations
✔️ Calculation of average order value per customer
✔️ Identification of top-selling products (by quantity & revenue)
✔️ Analysis of sales by product category and type
📈 Excel Skills Used:
🔹 Pivot Tables & Pivot Charts
🔹 Data Cleaning & Formatting
🔹 Use of Functions (SUM, AVERAGE, IF, etc.)
🔹 Data Visualization (Charts & Dashboards)
💡 Key Learning:
This project helped me understand how Excel can be used as a powerful tool for data analysis and how insights can drive better business decisions.
📌 Tools Used: Microsoft Excel
